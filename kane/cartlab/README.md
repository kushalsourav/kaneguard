# CartLab acceptance objectives
The source of truth for browser acceptance criteria is `configs/cartlab.json`. These are natural-language objectives passed unchanged to the authentic `kane-cli run ... --agent --headless` command.

The pricing rule is: SAVE10 takes 10% off subtotal; orders at least $100 subtotal get free shipping, otherwise $6.99; tax is 8% of discounted merchandise (shipping not taxable). No payment is processed.
