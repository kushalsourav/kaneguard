# Local regression proof ledger

Starting with v31, KaneGuard saves per-project protected browser objectives here **after genuine final-suite PASS evidence**. Later builds execute them again on the current source. These objectives are not native Kane assurance coverage.

`*.json` files are Git-ignored by default because they may contain local hostnames, app routes and user-supplied requirements. Review them before manually publishing any particular file. Deleting or editing a ledger directly may invalidate protection; use the run deletion workflow for provenance-sensitive cleanup.
